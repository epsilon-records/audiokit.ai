01 · submit

One request per job

Your job ID is the idempotency key. Retry freely: the same request never runs twice.

02 · verify

Checked before it runs

AudioKit downloads from your signed URL and rejects any file whose sha256 doesn't match.

03 · process

Originals untouched

Results carry provenance: input hash, AudioKit version, operation and settings.

04 · deliver

Signed webhooks

HMAC-signed events, retried for hours if your endpoint is down. Status is always one GET away.
